# Assignment 5 — JavaScript Basics

A simple HTML, CSS and JavaScript project for Web 1 Technologies.

## Pages

- `index.html`: Tasks 0–1, alert, console output, variables and operators.
- `dom.html`: Tasks 2–4, changing text and styles, adding and removing items.
- `events.html`: Tasks 5–7, mouse events, keyboard events and calculator.
- `todo.html`: Task 8, adding, completing and deleting tasks stored in an array.

## How to run

1. Replace `Your full name` and `Your group` in `basics.js` with your details.
2. Open `index.html` in a browser. No installation is needed.
3. Close the welcome alert and open Developer Tools (F12), then Console, to see Tasks 0–1.
4. Use the navigation links to open the other parts.

To-Do tasks disappear when the page is reloaded or closed.

## Publish with GitHub Pages

1. Create a GitHub repository and upload all files from this folder to its root.
2. Open the repository's Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and / (root), then save.
5. After deployment, open the website link shown on the Pages screen.
6. Submit the repository link and the published website link.
